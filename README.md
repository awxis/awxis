### Ishtirak Microfinance — Loan Origination Portal

`Angular 19` `.NET 8` `ASP.NET Core Web API` `EF Core` `ADO.NET` `MS SQL Server`

Digital loan origination covering the full lifecycle: application intake,
multi-stage verification, credit approval and disbursement — at 100,000+ loan
applications a month. Integrated third-party KYC and credit services for
automated due diligence: national identity verification (NADRA), security
screening (NACTA) and credit history (Credit Information Bureau). Role-based
access control across officer, verifier and approver workflows.

### IshtirakPay — Web Platform

`Angular` `ASP.NET Core Web API` `JWT` `MS SQL Server`

Extended an existing mobile product to the browser — sign-up, authentication and
core user flows against the same shared backend, so one account works from either
client without forking the mobile auth path.

### Edu Pharma Manager — VB 6.0 → .NET 8 Migration

`C#` `.NET 8` `WPF` `Avalonia UI` `ADO.NET` `MS SQL Server`

Migrated a business-critical pharmaceutical management system off VB 6.0 without
interrupting the business running on it. Rebuilt pricing, inventory and
profit-analysis modules on optimised stored procedures, and refactored a legacy
monolith into a clean multi-layer architecture.

### Financial Reporting — Credit Bureau & Portfolio

`.NET` `ASP.NET Core` `MS SQL Server` `Stored Procedures`

Reporting engine that transforms disbursed and overdue loan data into the credit
bureau's prescribed regulatory submission format (Tasdeeq), plus Recovery and
Portfolio reporting across large loan datasets.

### Employee Automation System — HRM & Payroll

`Blazor Server` `.NET 9` `EF Core` `MS SQL Server` `Bootstrap 5`

Onboarding, offboarding, attendance, leave workflows, asset allocation and
payroll with automated salary calculation and deductions. **Reduced manual HR
effort by 40%.**

### Remote Desktop Application

`WPF` `SignalR` `.NET Core` `C#`

AnyDesk-style remote access: live screen sharing, remote keyboard and mouse
control, and secure file transfer over a persistent SignalR connection on a
